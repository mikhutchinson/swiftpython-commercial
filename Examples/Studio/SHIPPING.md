# SwiftPython Studio 0.1.0

Studio is a historical example built with SwiftPython 0.5.14. Its standalone
[0.1.0 release](https://github.com/mikhutchinson/swiftpython-commercial/releases/tag/studio-v0.1.0)
is available on GitHub.

For new applications, use the current [SwiftPython getting-started guide](https://swiftpython.dev/docs/getting-started/)
and [packaging guide](https://swiftpython.dev/docs/packaging/). Preview 1 includes
Python and supports app-owned XPC and ExtensionFoundation workers.

The build scripts in this branch belong to the older Studio application. Keep
its runtime and helper versions together; its Homebrew setup and bundling steps
are not instructions for the current SDK.
